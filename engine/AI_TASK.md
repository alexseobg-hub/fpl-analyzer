# Дневна AI задача (Claude, планирана задача)

1. `python engine/build.py` → генерира `docs/digest.json` (~3–4 KB). Чети САМО него, не `data.json`.
2. Firecrawl: най-много 3 търсения (последната седмица): общи новини за отборите за следващия кръг + по едно за най-важните съмнения в моя отбор/целите. Без scrape, освен ако откъсът не стига за ключов играч (максимум 1).
3. Запиши `docs/ai.json` по схемата: `generated` (ISO UTC), `gw`, `summary` (4–6 изречения на български), `actions` (2–5 конкретни стъпки), `players` (до 6: `name`, `note`, `url` с https).
4. Перифразирай, без цитати от статиите. Не измисляй новини; ако няма нищо ново, кажи го.
5. `git add docs/ai.json && git commit && git push` → push-ът пуска GitHub Actions, който публикува таблото.
